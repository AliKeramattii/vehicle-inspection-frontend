# Vehicle identity render

`identity-suv.png` was generated with the built-in imagegen tool on 2026-10-04 for Phase 03.
It is an isolated, unbranded silver SUV render with alpha transparency and a front three-quarter
view pointing right. The prompt specified bright studio lighting, no UI/labels/logos/watermarks,
natural proportions and a subtle contact shadow, to follow 06-vehicle-identity.png's automotive
direction without rendering the reference PNG or mirroring an existing physical vehicle asset.
All page text, vehicle metadata, plate and controls remain separate semantic DOM components.
The original Phase-01/02 assets remain unchanged. This bitmap is only a configurator illustration,
not a 3D viewer or evidence of the inspected vehicle's exact appearance.
