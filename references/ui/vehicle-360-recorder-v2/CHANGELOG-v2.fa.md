# تغییرات نسخه ۲ — Ghost Guide تصویری ۸ زاویه

- ۸ تصویر `WebP` واقعی با پس‌زمینه شفاف، به‌جای SVGهای قبلی خودرو.
- فایل‌های تصاویر: `assets/360-recording/ghost-guides/ghost-*.webp`؛ تصویر نماهای مختلف از `manifest.json` قابل شناسایی است.
- ترتیب کنترل دستی: جلو، جلو ۴۵ راست، راست، عقب ۴۵ چپ، عقب، عقب ۴۵ راست، چپ، جلو ۴۵ چپ.
- بخش Ghost در برنامه و CSS به‌روزرسانی شده و تصاویر با opacity پیش‌فرض ۰٫۴۴ روی تصویر زنده نمایش داده می‌شوند.
- چک‌لیست و پیش‌نمایش کنار هم در `mockups/eight-ghost-guides-contact-sheet.png`.
- اسکریپت‌های خروجی ماکاپ فارسی به فایل WebP و راهنمای ۸ زاویه متصل شده‌اند.
- کد ضبط دوربین-only،‌ IndexedDB، تایمر و نقطه اتصال upload queue نسخه قبل حفظ شده است.
- تست‌های واحد Node: ۶ از ۶ موفق؛ تست واقعی مرورگر در این محیط به‌علت خطای `ERR_BLOCKED_BY_ADMINISTRATOR` امکان‌پذیر نبود.

**مهم:** خود نسخه مستقل به API بک‌اند پروژه اصلی متصل نیست. برای ساخت evidence و ارسال واقعی باید bridge/upload queue قبلی را یکپارچه کنید. تصویر ghost فقط کمک‌قاب‌بندی است و تشخیص هوشمند پوشش ۳۶۰ درجه انجام نمی‌دهد.

این تصاویر طراحی نمونه generic SUV هستند؛ اگر انطباق هندسی دقیق و بدون تفاوت مدل در هر هشت نما لازم است، باید از یک مدل سه‌بعدی واحد با دوربین ثابت و زاویه‌های دقیق رندر گرفت.
