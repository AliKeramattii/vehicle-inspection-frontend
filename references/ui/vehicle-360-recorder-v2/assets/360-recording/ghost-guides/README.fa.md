# راهنمای تصویری ۸ زاویه Ghost Guide

هر فایل `ghost-*.webp` یک تصویر واقعی Raster با کانال آلفای شفاف است؛ هیچ Ghost SVG در این فولدر وجود ندارد.

زاویه‌ها از دید خودرو تعریف می‌شوند (سمت راست یا چپ خودرو)، نه راست یا چپ صفحهٔ نمایش. فایل‌های اصلی به صورت دستی انتخاب شده‌اند و سمت خودرو برای ساخت زاویهٔ جدید آینه نشده است.

| مرحله | زاویه | نام فایل |
|---:|---|---|
| 1 | جلو | `ghost-front.webp` |
| 2 | جلو ۴۵ درجه راست | `ghost-front-45-right.webp` |
| 3 | راست | `ghost-right.webp` |
| 4 | عقب ۴۵ درجه چپ | `ghost-rear-45-left.webp` |
| 5 | عقب | `ghost-rear.webp` |
| 6 | عقب ۴۵ درجه راست | `ghost-rear-45-right.webp` |
| 7 | چپ | `ghost-left.webp` |
| 8 | جلو ۴۵ درجه چپ | `ghost-front-45-left.webp` |

این ۸ نما یک دور ۳۶۰ درجه با گام‌های ۴۵ درجه را پوشش می‌دهند. اما *ترتیب درخواستی* با مسیر فیزیکی پیوسته دور خودرو یکسان نیست: برای پیاده‌روی ساعت‌گرد ترتیب مناسب معمولاً جلو ← جلو۴۵راست ← راست ← عقب۴۵راست ← عقب ← عقب۴۵چپ ← چپ ← جلو۴۵چپ است. این نسخه مطابق ترتیب صریح درخواستی نام‌گذاری و در UI چیده شده است.

در داخل برنامه برای شفافیت بیشتر، CSS `opacity` روی خود `<img>` تنظیم می‌شود. راهنما نباید در ویدیوی واقعی ضبط شود؛ MediaRecorder باید MediaStream دوربین اصلی را ثبت کند.
