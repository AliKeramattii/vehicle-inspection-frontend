# سیستم رنگ سامانه بازدید خودرو

## جهت طراحی

پیشنهاد پیش‌فرض: **زمردی + کهربایی + Slate**. رنگ آبی دیگر نقش اصلی برند را ندارد و فقط برای انتخاب/اطلاعات محدود به کار می‌رود. هدف: ظاهری مطمئن، حرفه‌ای، کم‌نویز و مناسب عکس‌های سدان سفید.

### نقش‌های اصلی

## کجا چه رنگی استفاده شود؟

- **صفحات مشتری**: پس‌زمینه روشن Slate؛ کارت سفید؛ دکمه اصلی زمردی؛ نقاط تأکیدی کهربایی به‌ندرت؛ وضعیت انتخاب نما فقط در صورت لزوم آبی Sky.
- **عکاسی 2D/3D**: خاکستری = در انتظار؛ سبز = عکس تأییدشده در ذخیره محلی (با برچسب دقیق)، آبی = انتخاب فعلی؛ کهربایی/نارنجی = درخواست اصلاح؛ قرمز = خطا. وضعیت آپلود جداگانه باقی بماند.
- **ویدیوی 360**: رنگ اکشن زمردی؛ قرمز فقط برای ضبط زنده/هشدار مرتبط؛ Ghost Guides شفاف سفید/فیروزه‌ای طبق دارایی‌های مرجع (نباید بر اثر تم رنگ‌آمیزی شوند).
- **ادمین**: سایدبار Slate تیره؛ گزینه فعال زمردی؛ محتوا کارت سفید روی Slate روشن؛ هشدارها کهربایی؛ مد تاریک با سطح‌های Slate و متن روشن.
- **کارشناس**: تصویر/ویدیو محور اصلی است؛ تصمیم تأیید سبز، رد/خطا قرمز، نیاز به عکاسی مجدد کهربایی، انتخاب مدرک Sky محدود.
- **نشان**: رنگ نقشه/کاشی‌های سرویس‌دهنده، لوگوی نشان و attribution دست‌نخورده باقی بمانند. رنگ فیروزه‌ای فقط برای کنترل‌های مخصوص نقشه کاربرد داشته باشد.
- **White-Label**: این پالت پیش‌فرض است. رنگ برند کارگزاری در جایگاه تعریف‌شده برند قابل تغییر باقی بماند. وضعیت‌های success/warning/error و دسترسی‌پذیری تابع رنگ دلخواه کارگزاری نیستند.

## حالت تاریک

`[data-vi-theme="dark"]` صرفاً قرارداد فایل پیش‌نمایش است. Codex باید با مکانیزم موجود `light/dark/system` پروژه تطبیق دهد، نه اینکه سیستم تم جدید و موازی بسازد. کنتراست متن، CTA، رنگ انتخاب و پیام وضعیت باید در حالت روشن و تاریک بررسی شود.

## کارهای ممنوع

- رنگ‌آمیزی همگانی تمام دکمه‌ها و کارت‌ها با آبی.
- استفاده تصادفی از چند رنگ مختلف برای Primary.
- تغییر رنگ سبز موفقیت به رنگ دلخواه کارگزاری.
- تزریق مستقیم HEX/LAB در ده‌ها کامپوننت به‌جای نقش‌های معنایی.
- تغییر مدل GLB، جریان عکس/ویدیو، بیزنس‌لاجیک یا قرارداد API در یک تسک صرفاً رنگ.
- جایگزینی خودکار اسکرین‌شات‌های تاریخی بدون تأیید.

## فایل‌ها

`vehicle-palette.css` شامل مقادیر **دقیق** primitive LAB ارائه‌شده توسط کاربر و نگاشت‌های پیشنهادی معنایی است. در اپ، رنگ‌ها در محل مناسبِ توکن‌های موجود یکپارچه شوند؛ از تعریف مجدد ناخواسته Tailwind یا ایجاد دو منبع حقیقت خودداری شود.

`palette-preview.html` صرفاً پیش‌نمایش آفلاین رنگ و رفتار حالت تاریک است، نه طرح صفحه نهایی یا کد اجرایی پروژه.
