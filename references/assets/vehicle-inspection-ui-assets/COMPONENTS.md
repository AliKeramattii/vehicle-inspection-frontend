## Motion
- UI transitions: 150–250ms.
- Bottom sheets: 300–450ms.
- Selected pin pulse: 1.8s only when useful.
- All repeating/large motion must stop or simplify under `prefers-reduced-motion`.

## Skeleton strategy
`vehicle-viewer-skeleton`, `shot-card-skeleton`, `vehicle-card-skeleton`, and `media-thumbnail-skeleton` are implemented as CSS skeleton variants rather than SVG.
