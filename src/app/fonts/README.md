# Local Persian typography

`Vazirmatn-Variable.woff2` is the unmodified variable font from the official
[Vazirmatn v33.003 repository](https://github.com/rastikerdar/vazirmatn/tree/v33.003).
Its SIL Open Font License is included in `OFL.txt`.

The root layout loads it through `next/font/local` with `display: swap`, weights 100–900,
and Tahoma/Arial/sans-serif fallbacks. Builds and page rendering do not require a font CDN.
Do not replace it with IRANSansX without the appropriate production license.
